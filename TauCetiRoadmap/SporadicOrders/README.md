# Roadmap: orders of the sporadic groups from permutation representations

The goal of **SporadicOrders** is to give each sporadic simple group of small permutation degree a
concrete permutation model whose order is a theorem, and to connect that model to the presentation
that [CFSGStatement](../CFSGStatement/README.md) uses to define the group. For each covered name we
want:

```lean
theorem card_M24 : Nat.card SporadicOrders.M24 = 244823040
theorem exists_surjective_M24 :
    ∃ f : TauCeti.SporadicName.M24.Group →* SporadicOrders.M24, Function.Surjective f
```

where `SporadicOrders.M24 : Subgroup (Equiv.Perm (Fin 24))` is the subgroup generated by the
permutations of a named ATLAS file and `TauCeti.SporadicName.M24.Group` is the `PresentedGroup` of
the presentation that CFSGStatement pins for that name. The first theorem pins the order of the
model. The second shows that the transcribed relators hold of permutations that generate the model,
so the presented group is at least as large as the model; in particular it is nontrivial, which is
exactly the check that catches a relator transcribed wrongly enough to collapse the group.

This roadmap does not prove simplicity, does not identify the presented group with the model (that
needs an upper bound on the presented group, see *Beyond this roadmap*), and does not treat groups of
Lie type.

Suggested home in Tau Ceti: `TauCeti/GroupTheory/SpecificGroups/Sporadic/Orders/`.

## Dependency: kernel certificates for permutation groups

The orders are proved by the `perm_group` tactic of the Hex library `hex-perm-group-mathlib`, which
checks a stabilizer-chain certificate in the kernel and applies the soundness theorem
`Hex.PermGroup.Kernel.card_closure`. The tactic proves, from closed generators,

```lean
Nat.card (Subgroup.closure ({σ₁, …, σₖ} : Set (Equiv.Perm (Fin n)))) = N
g ∈ Subgroup.closure ({σ₁, …, σₖ} : Set (Equiv.Perm (Fin n)))
Subgroup.closure ({σ₁, …, σₖ} : Set (Equiv.Perm (Fin n))) = ⊤
```

and the negation of the membership goal, with only `propext`, `Classical.choice` and `Quot.sound` as
axioms. The released package is
[leanprover/hex-perm-group-mathlib](https://github.com/leanprover/hex-perm-group-mathlib); O0 adds it
as a Tau Ceti dependency.

## Existing work

[FiniteSimpleGroups](https://github.com/KitaKen1/finite-simple-groups-lean) (Apache-2.0) proves the
orders and simplicity of `M11 M12 M22 M23 M24 J1 J2 HS McL Co3 Suz Co2 Fi22 He` as subgroups of
`Equiv.Perm (Fin n)`, by kernel-checked stabilizer chains closed with Witt designs, strongly regular
graphs and parity certificates, some needing a 128 GiB host. This roadmap takes a different route,
one general certificate checker rather than per-group arguments, and its order targets overlap that
work for ten names. The models here are the ATLAS files named in O1; that work is an independent
source of the same orders, not a source of definitions.

## O1: permutation models and their orders

For each name below, define `SporadicOrders.<Name> : Subgroup (Equiv.Perm (Fin n))` as the closure of
the two permutations in the listed files of the
[ATLAS of Group Representations, version 3](https://brauer.maths.qmul.ac.uk/Atlas/v3/) (the same
files ship with GAP's AtlasRep package under these names), and prove
`Nat.card SporadicOrders.<Name> = N` by `perm_group`. The files are the ATLAS's first and second
standard generators; the roadmap uses them as the provenance of the models and makes no claim about
standardness.

Each file lists the images of the points `1, …, n`. The point `i` becomes `(i - 1 : Fin n)`, so the
generator is the `σ : Equiv.Perm (Fin n)` with `σ (i - 1) = image i - 1`. Write it with
`Hex.PermGroup.Kernel.permOfImages n [...]` on these 0-based images, so that the statement
elaborates in time linear in `n`. Cite the file name in the docstring of the definition.

| name | degree | order | ATLAS files |
|---|---|---|---|
| `M11` | 11 | 7920 | `M11G1-p11B0.m1`, `.m2` |
| `M12` | 12 | 95040 | `M12G1-p12aB0.m1`, `.m2` |
| `M22` | 22 | 443520 | `M22G1-p22B0.m1`, `.m2` |
| `M23` | 23 | 10200960 | `M23G1-p23B0.m1`, `.m2` |
| `M24` | 24 | 244823040 | `M24G1-p24B0.m1`, `.m2` |
| `J1` | 266 | 175560 | `J1G1-p266B0.m1`, `.m2` |
| `J2` | 100 | 604800 | `J2G1-p100B0.m1`, `.m2` |

Every proof must build within the default `maxHeartbeats` and without `set_option maxHeartbeats`.

## O2: the presentations hold in the models

For each name in O1, choose an explicit permutation `τᵢ : Equiv.Perm (Fin n)` for each generator of
CFSGStatement's presentation, written with `permOfImages`, and prove:

- each relator holds of the `τᵢ`, a closed permutation equation proved by `decide +kernel`;
- `Subgroup.closure {τ₁, …, τₖ} = SporadicOrders.<Name>`, by `perm_group` membership goals in both
  directions: each `τᵢ` lies in the model and each ATLAS generator lies in the closure of the `τᵢ`.

Then `PresentedGroup.toGroup` gives a hom to `Equiv.Perm (Fin n)` whose range is the model, hence the
surjection onto the model. Products of permutations follow Mathlib's convention,
`(σ * τ) x = σ (τ x)`, which is the reverse of GAP's and the ATLAS's left-to-right products, so a word
taken from those sources is reversed when written in Lean. How the `τᵢ` are found is not part of the
target; the second condition makes any choice that satisfies the relators acceptable, whether or not
the presentation's generators are the ATLAS standard generators.

Derive `Nontrivial TauCeti.SporadicName.<Name>.Group` and
`0 < Nat.card TauCeti.SporadicName.<Name>.Group → N ≤ Nat.card TauCeti.SporadicName.<Name>.Group`
from the surjection and O1.

## Beyond this roadmap

This section is motivation for later roadmaps, not work to attempt here.

The remaining sporadic groups with a faithful permutation representation of a few thousand points
(`He` 2058, `Suz` 1782, `Co2` 2300, `Fi22` 3510, `Ru` 4060, `J3` 6156) are within reach of the same
certificates once their kernel cost is measured; the rest (`Co1`, `Fi23`, `Fi24'`, `HN`, `Ly`, `Th`,
`O'N`, `J4`, `B`, `M`) need matrix-group certificates. Identifying each presented group with its
model needs an upper bound on the presented group, by a kernel-checked coset enumeration
certificate, which would turn O2's surjection into an isomorphism and give `Nat.card` of the
CFSGStatement group itself.
