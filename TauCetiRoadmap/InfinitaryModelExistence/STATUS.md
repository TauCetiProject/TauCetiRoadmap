## Where this roadmap stands

**At a glance.** Model existence, the omitting types theorem, Craig interpolation with PC separation, and the boundedness of well-orderings are all proved, and so are Morleyization and the graph translation. What remains is Lyndon and Malitz interpolation, the first-order corollaries of Layers 2 and 4 together with the first-order image fragment they rest on, and a few items of the Layer 0 signature calculus.

### Named results

- **Model existence** — over a language with countably many symbols, a countable member of a consistency property has a countable model, in any universe, in which every element names a Henkin constant. It is built as the term model of a fairly enumerated Henkin-complete limit: [`ConsistencyProperty.model_existence`](https://taucetiproject.org/docs/TauCeti/ModelTheory/ModelExistence/ModelExistence.html#FirstOrder.Language.ConsistencyProperty.model_existence), with the [omission-request form](https://taucetiproject.org/docs/TauCeti/ModelTheory/ModelExistence/ModelExistence.html#FirstOrder.Language.ConsistencyProperty.model_existence_omitting).
- **The omitting types theorem** — a satisfiable theory in a countable formation-closed fragment has a countable model omitting countably many non-isolated partial types of the fragment: [`Theoryω.exists_countable_model_omitting`](https://taucetiproject.org/docs/TauCeti/ModelTheory/ModelExistence/OmittingTypes.html#FirstOrder.Language.Theoryω.exists_countable_model_omitting). The acceptance check, that a type realized in every countable model is isolated, is [`Theoryω.isolatesIn_of_realized_in_every_countable_model`](https://taucetiproject.org/docs/TauCeti/ModelTheory/ModelExistence/OmittingTypes.html#FirstOrder.Language.Theoryω.isolatesIn_of_realized_in_every_countable_model).
- **Craig interpolation for Lω₁ω sentences** — if one sentence entails another, over a language of any cardinality with function symbols, some sentence in their shared symbols lies between them: [`craig_interpolation`](https://taucetiproject.org/docs/TauCeti/ModelTheory/Interpolation/Craig.html#FirstOrder.Language.craig_interpolation). The relational core comes first, and the graph translation then carries the result to languages with function symbols.
- **PC separation** — two projective classes with no countable common member are separated by a single Lω₁ω sentence of the base language, in every universe: [`pcSeparation`](https://taucetiproject.org/docs/TauCeti/ModelTheory/Interpolation/Craig.html#FirstOrder.Language.pcSeparation). This is the interface the CountableStructureSpaces roadmap consumes.
- **Boundedness of well-orderings** — if a sentence forces `lt` to well-order its models, their order types are bounded below ω₁ ([`Sentenceω.wellOrder_type_boundedness`](https://taucetiproject.org/docs/TauCeti/ModelTheory/WellOrdering.html#FirstOrder.Language.Sentenceω.wellOrder_type_boundedness)), so [no sentence defines well-ordering](https://taucetiproject.org/docs/TauCeti/ModelTheory/WellOrdering.html#FirstOrder.Language.wellOrdering_undefinable). Both hold for arbitrary languages.

### Notable definitions and infrastructure

- **Fragments** — [a countable set generates a countable fragment over any language](https://taucetiproject.org/docs/TauCeti/ModelTheory/Infinitary/Fragment.html#FirstOrder.Language.Fragment.generated_countable). Fragments make [downward Löwenheim–Skolem](https://taucetiproject.org/docs/TauCeti/ModelTheory/ModelExistence/LowenheimSkolem.html#FirstOrder.Language.exists_aElementary_substructure) possible, which in turn shows that [entailment does not depend on the universe of models](https://taucetiproject.org/docs/TauCeti/ModelTheory/ModelExistence/CountableModel.html#FirstOrder.Language.Theoryω.Entails.realize). PC separation uses that invariance to pass from countable structures to all of them.
- **The graph translation** — [`relationalize`](https://taucetiproject.org/docs/TauCeti/ModelTheory/Infinitary/GraphTranslation/Relationalize.html#FirstOrder.Language.BoundedFormulaInf.relationalize) replaces function symbols by their graphs. It comes with graph axioms, reconstruction, a back-translation and entailment transfer, and this is how relational interpolation reaches languages with function symbols.
- **Morleyization** — the [Morleyization](https://taucetiproject.org/docs/TauCeti/ModelTheory/ModelExistence/Morleyization.html#FirstOrder.Language.morleyize) of a fragment turns fragment-elementary embeddings into embeddings. Its first-order Morley theory and omitted types characterize the canonical expansion exactly. The finiteness example shows that the omitted types do real work.

## The frontier

- **The first-order image fragment** — the formulas `toOmega φ` with `φ` first-order, shown to form a formation-closed fragment that is countable for a countable language. Layers 1, 2 and 4 each wait on it.
- **First-order omitting types** — derive the countable first-order omitting types theorem from the fragment theorem by taking the first-order image fragment.
- **Lyndon interpolation** — the relational core, refining the Craig separator class to signed pairs, and then the arbitrary-language form through the graph translation. The polarity laws for the translation are already in place.
- **Malitz interpolation** — the universal interpolant for relational languages with a universal consequent, by the budgeted-pair engine. The quantifier-class syntax and the preservation lemmas are done.
- **Layer 0 remainders** — injectivity of the formula map, the formula equivalence induced by a language equivalence, `expandSymbStructure` and the infinitary `toFormula`.
