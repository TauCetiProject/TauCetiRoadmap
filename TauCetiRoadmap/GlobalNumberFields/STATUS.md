### Named results

- **The ray class ideal count** — every ray class has the same main coefficient, including the Euler factors at primes dividing the modulus, and a uniform power-saving error ([`TauCeti.GlobalNumberFields.rayClassIdealCount`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/RayClass/Count/Asymptotic.html#TauCeti.GlobalNumberFields.rayClassIdealCount)).
- **Finite-order Hecke characters are ray class characters** — a Hecke character has finite order exactly when it factors through some ray class group ([`TauCeti.GlobalNumberFields.HeckeCharacter.isFiniteOrder_iff_exists_rayClassCharacter`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/HeckeCharacter/FiniteOrder.html#TauCeti.GlobalNumberFields.HeckeCharacter.isFiniteOrder_iff_exists_rayClassCharacter)). Over `ℚ` these are exactly the characters coming from Dirichlet characters, each with a unique primitive representative ([`TauCeti.GlobalNumberFields.HeckeCharacter.existsUnique_primitive_dirichletCharacter`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/HeckeCharacter/Dirichlet.html#TauCeti.GlobalNumberFields.HeckeCharacter.existsUnique_primitive_dirichletCharacter)).
- **The cyclotomic ray class group is the Galois group** — the ray class group of `ℚ` modulo `(n)·∞` is `Gal(ℚ(ζ_n)/ℚ)`, and the ray class of a prime not dividing `n` is its arithmetic Frobenius ([`TauCeti.GlobalNumberFields.ratModulusEquivGal`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/Cyclotomic/RayClass.html#TauCeti.GlobalNumberFields.ratModulusEquivGal)).
- **The Picard group of an order is a ray class quotient** — `Pic O` is the image of the ray class group of the conductor, with kernel the classes of ideals generated by an element of the order, so `Pic O` is finite ([`TauCeti.GlobalNumberFields.NumberFieldOrder.mem_ker_rayClassToPic`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/Orders/RayClass.html#TauCeti.GlobalNumberFields.NumberFieldOrder.mem_ker_rayClassToPic)).
- **The Gorenstein criterion** — an order is Gorenstein exactly when every proper fractional ideal is invertible, and every monogenic order `ℤ[x]` is Gorenstein ([`TauCeti.GlobalNumberFields.NumberFieldOrder.isGorenstein_iff_forall_isUnit`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/Orders/Gorenstein.html#TauCeti.GlobalNumberFields.NumberFieldOrder.isGorenstein_iff_forall_isUnit)).

### Notable definitions and infrastructure

- **Topological adele base change** `𝔸_K ⊗_K L ≃ 𝔸_L` is a continuous algebra equivalence that composes in towers, so idelic arguments can move open sets between `K` and `L` ([`TauCeti.GlobalNumberFields.adeleBaseChangeEquiv_tower`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/Adeles/BaseChange.html#TauCeti.GlobalNumberFields.adeleBaseChangeEquiv_tower)).
- **Base change of Hecke characters** is pullback along the idele class norm. It preserves algebraicity and acts on infinity types as the local norms dictate ([`TauCeti.GlobalNumberFields.HeckeCharacter.baseChange`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/HeckeCharacter/BaseChange.html#TauCeti.GlobalNumberFields.HeckeCharacter.baseChange)).
- **The trace dual of a fractional ideal of an order** is a perfect duality, and an ideal `I` is proper exactly when `I I^∨ = O^∨`. This is the tool behind the Gorenstein criterion and the multiplier-ring computations ([`TauCeti.GlobalNumberFields.NumberFieldOrder.dual`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/NumberTheory/NumberField/Global/Orders/Gorenstein.html#TauCeti.GlobalNumberFields.NumberFieldOrder.dual)).
