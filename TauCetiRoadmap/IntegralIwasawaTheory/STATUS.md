- **A norm criterion for Hasse index one**: in a CM field, if |N(ζ − 1)| is not a rational square for some root of unity ζ, then the index is one ([`indexRealUnits_eq_one_of_not_isSquare_abs_norm`](https://taucetiproject.org/docs/TauCeti/NumberTheory/NumberField/Units/HasseUnitIndex.html#TauCeti.NumberField.IsCMField.indexRealUnits_eq_one_of_not_isSquare_abs_norm)). The prime-power result follows because N(ζ − 1) = p for a primitive p^a-th root of unity with p^a > 2.
