## GeometricCurrents: 2026-10-23 to 2026-10-24 (`3150404` to `5d671b9`)

This first window for the roadmap puts the Euclidean pieces of the constancy theorem in place. On an open set of an oriented finite-dimensional real space there is now the oriented integration current [`integrationCurrent`](https://taucetiproject.org/docs/TauCeti/Analysis/Distribution/TestFunction/IntegrationCurrent.html#Orientation.integrationCurrent), the functional that integrates a compactly supported top-degree form, and it has zero boundary: by [`integrationCurrent_extDerivCLM`](https://taucetiproject.org/docs/TauCeti/Analysis/Distribution/TestFunction/IntegrationCurrent.html#Orientation.integrationCurrent_extDerivCLM) it kills every exact test form, which is Stokes' theorem for compactly supported forms (TauCeti#20490). It changes sign when the orientation is reversed and is a Dirac mass in dimension zero. Under it sits the exterior derivative on test forms as a continuous linear map, [`extDerivCLM`](https://taucetiproject.org/docs/TauCeti/Analysis/Distribution/TestFunction/ExtDeriv.html#TestFunction.extDerivCLM), with d∘d = 0, together with the reduction showing that a top-degree current with zero boundary kills every derivative of a scalar test function.

For the other half of the argument, regularization arrived: pairing a distribution with translates of a fixed test function gives a smooth function whose derivative is the regularization of the distributional derivative ([`fderiv_translatePairing_apply`](https://taucetiproject.org/docs/TauCeti/Analysis/Distribution/Regularization.html#Distribution.fderiv_translatePairing_apply)). So a distribution with vanishing derivatives has [locally constant regularizations](https://taucetiproject.org/docs/TauCeti/Analysis/Distribution/Regularization.html#Distribution.translatePairing_eq_of_lineDerivOp_eq_zero) (TauCeti#20243). On the way came the fact that every distribution has [finite order on each compact set](https://taucetiproject.org/docs/TauCeti/Analysis/Distribution/Order.html#Distribution.exists_norm_apply_le). Separately, [`dualEquivDistribution`](https://taucetiproject.org/docs/TauCeti/Analysis/Distribution/TestFunction/DualEquiv.html#TestFunction.dualEquivDistribution) identifies maps on vector-valued tests with operator-valued distributions, compatibly with derivatives.

Two things are still missing: the scalar criterion itself, that a distribution with vanishing derivatives on a connected open set is a constant multiple of Lebesgue measure, and the constancy theorem built from it. Everything so far lives on Euclidean open sets. The manifold carrier of test forms and currents, and mass, have not been started.
