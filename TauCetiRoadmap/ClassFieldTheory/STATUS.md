## The frontier

- **The Tate cup product** — cup products in all integer bidegrees, with associativity, graded commutativity, naturality and the projection formula. This is the one remaining Layer 0 prerequisite for everything downstream.
- **The cup-product criterion of Tate's theorem** — the generic statement (Artin–Tate, Preliminaries §2, Theorem A), with its three hypotheses as explicit arguments. It is blocked on the cup product. The Sylow reduction it needs has already landed.
- **`tateIso` for a class formation** — apply the criterion to the fundamental class and the three Layer 2 theorems, which are already available. Then prove the restriction, corestriction, tower, conjugation and scaled-inflation compatibilities.
- **The abstract Artin map and norm limitation** — `nakayamaNegTwo`, `artinEquiv` and `artinMap`, with the kernel, surjectivity, the four Artin–Tate diagrams, the character formula, and `normSubgroup_maximalAbelianLayer`. The low-degree identifications and the maximal abelian sublayer are ready; the map waits on Layer 3.
- **The local Brauer group and its invariant (Layer 5)** — this layer depends only on Layer 0 and the neighbouring suppliers, not on Layers 1–4, so it can start in parallel. Nothing towards it has landed.
