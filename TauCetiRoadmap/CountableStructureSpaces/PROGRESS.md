## CountableStructureSpaces: 2026-11-20 to 2026-11-25 (`26eb654` to `522d48f`)

López–Escobar's theorem is now in the shape this roadmap asks for. The library's [form](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/LopezEscobar.html#TauCeti.RelationalConfiguration.exists_modelsOf_eq_iff) says that the isomorphism-invariant Borel classes of countable structures are exactly the model classes of single Lω₁ω sentences. It now holds for relational languages of any cardinality. The new step that makes this possible is [invariant analytic separation](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/Orbit/Separation.html#TauCeti.RelationalConfiguration.invariant_analytic_separation) for every language, which first passes to a countable sublanguage that already separates the two classes (TauCeti#45727). On top of this sit the [action form](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/LopezEscobar.html#TauCeti.RelationalConfiguration.lopezEscobar_action_iff) and the statement that the [invariant σ-algebra is exactly the collection of model classes](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/InvariantSigmaAlgebra.html#TauCeti.RelationalConfiguration.measurableSet_iInf_invariants_iff_exists_modelsOf). The relational [PC sentence of a tree](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/PCSentence.html#TauCeti.RelationalConfiguration.pcSentence) arrived with its completeness and soundness. It shows that, with countably many symbols, the [invariant analytic classes are exactly the projective classes](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/AnalyticPC.html#TauCeti.RelationalConfiguration.analyticSet_iff_exists_pc).

The descriptive layers filled in as well. Trees gained bodies and the Kleene–Brouwer order, which is [well-founded exactly when the tree has no branch](https://taucetiproject.org/docs/TauCeti/SetTheory/Descriptive/KleeneBrouwer.html#Descriptive.wellFounded_kbLT_iff). A query code into Cantor space gives every analytic class of codes a [tree representation](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/QueryCode.html#TauCeti.RelationalConfiguration.exists_tree_of_analyticSet). Descending-sequence trees show that an [analytic set of coded well-orders has bounded order types](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/WellOrder.html#TauCeti.RelationalConfiguration.exists_type_lt_omega_one_of_analyticSet). So the well-order class is not analytic, not Borel, and [not the model class of any sentence](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/WellOrder.html#TauCeti.RelationalConfiguration.not_exists_modelsOf_eq_wellOrderClass). For isomorphism itself, it is [Borel on a class of bounded Scott height](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/BorelIsomorphism.html#TauCeti.RelationalConfiguration.measurableSet_iso_inter_of_scottHeight_le). On a Borel class it is Borel [exactly when one countable back-and-forth level decides it](https://taucetiproject.org/docs/TauCeti/ModelTheory/RelationalConfiguration/BorelIsomorphism.html#TauCeti.RelationalConfiguration.measurableSet_iso_inter_iff_exists_bfLevel).

Smaller work covered Gδ model classes of ∀∃ sentences, the dense-linear-order and Rado-graph examples, and continuity of the logic action. Still missing: the finite-cylinder basis, the graph-coding and cardinality refinements of Layer 0, and the locality and graph-event statements of Layer 2.
