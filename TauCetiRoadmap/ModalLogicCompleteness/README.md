# Roadmap: modal logic completeness

**Summary.** Propositional modal logic adds to classical propositional logic an operator `□`,
read "necessarily", with its dual `◇ = ¬□¬`. Its standard semantics is Kripke's: a model is a set
of worlds with an accessibility relation, and `□φ` is true at a world when `φ` is true at every
world it can access. This roadmap builds the syntax, the Hilbert-style proof systems and the Kripke
semantics of the basic modal language over an arbitrary set of propositional variables, and proves
that the six classical normal systems K, T, K4, S4, KTB (often called B) and S5 are exactly the
logics of their frame classes, in the strong form and with finite countermodels of bounded size.
No countability is assumed anywhere.

There are four main theorems.

- *Strong completeness.* For each of the six systems and every set `Γ` of formulas, `φ` is
  derivable from `Γ` if and only if `φ` is true at every world, of every model on a frame of the
  system's class, at which all of `Γ` is true. The classes are all frames for K, reflexive frames
  for T, transitive frames for K4, reflexive transitive frames for S4, reflexive symmetric frames
  for KTB, and equivalence relations for S5. More generally the same holds for the system
  generated by any set of Geach schemas `◇ʰ□ⁱφ → □ʲ◇ᵏφ`, over the frames that are convergent for
  each of its parameter tuples.
- *Frame correspondence (Lemmon and Scott).* The formula `◇ʰ□ⁱp → □ʲ◇ᵏp` is valid on a frame if
  and only if the frame is `(h, i, j, k)`-convergent: whenever `y` is reached from `x` in `h`
  steps and `z` in `j` steps, some world is reached from `y` in `i` steps and from `z` in `k`
  steps. The schemas T, 4, B and 5 are the cases that give reflexivity, transitivity, symmetry
  and the euclidean property. Correspondence is a statement about frames: a model on a frame that
  is neither reflexive nor transitive can make every instance of T and of 4 true.
- *The finite model property.* A formula is a theorem of one of the six systems if and only if it
  is valid on every frame of the system's class with at most `2^s` worlds, where `s` is the number
  of subformulas of the formula. The countermodels come from filtrations; for K4 and S4 the
  filtration must be chosen to be transitive, and for S5 the countermodel can be taken to be a
  finite universal frame.
- *Universality is not definable.* Equivalence relations and universal relations have the same
  local consequences, so no modal formula is valid on exactly the universal frames.

The roadmap builds on Mathlib alone, using its relation composition, quotients by setoids,
cardinalities of finite sets and Zorn's lemma; Mathlib has no modal logic.

Layer 1 below gives formulas, derivability and the six systems. Layer 2 gives Kripke semantics,
the Lemmon–Scott correspondence, universal frames and soundness. Layer 3 proves strong
completeness with canonical models built from maximal consistent sets. Layer 4 develops
filtrations and proves the finite model property.

## Conventions

- **Formulas.** `Formula α` has the constructors `var p`, `bot` (written `⊥`), `imp φ ψ` (written
  `φ → ψ`) and `box φ` (written `□φ`), for propositional variables `p` in an arbitrary type `α`,
  possibly empty or uncountable. Negation is `¬φ := φ → ⊥` and the diamond is `◇φ := ¬□¬φ`;
  conjunction and disjunction appear only in prose, as the usual abbreviations. Iterates are
  written with Mathlib's `Nat.iterate`, so `box^[i] φ` is `□ⁱφ` and `dia^[h] φ` is `◇ʰφ`. The
  source cited most (Zach's *Boxes and Diamonds*) takes `¬`, `∧`, `∨` and `◇` as primitive and a
  countably infinite set of variables; with fewer primitives the inductions below have fewer
  cases, and nothing depends on countability.
- **Systems.** A system is given by a set `Ax` of extra axioms, always a schema (closed under
  substitution) in the six systems; its theorems are `Proves Ax`. The schemas are `T: □φ → φ`,
  `4: □φ → □□φ`, `B: φ → □◇φ` and `5: ◇φ → □◇φ`. The system named B in many texts is KTB here.
  Derivability from hypotheses, `Derives Ax Γ φ`, never applies necessitation to a hypothesis, so
  it matches local consequence, not global consequence.
- **Frames and models.** A frame is a type `W` of worlds with a relation `R : W → W → Prop`; a
  model adds a valuation `V : α → Set W`. Frames may be empty; on the empty frame every formula is
  valid, so validity and consequence over a class are the same whether or not empty frames are
  admitted, and the source's requirement of a nonempty set of worlds is not imposed. Frame
  properties are written out as formulas about `R`; S5 uses Lean core's `Equivalence`.
- **Consequence.** `Entails C Γ φ` is local consequence over a class `C` of frames, taken over
  frames whose world type lies in the universe of `α`; this is where the canonical model lives.
  Validity of a single formula on a single frame, `FrameValid`, is universe-polymorphic.
- **Sizes.** `subformulas φ` is a `Finset`, so a subformula that occurs twice is counted once; the
  bound of the finite model property is `2 ^ (subformulas φ).card`.

## Layer 1: formulas and normal modal systems

### 1.1 Formulas

Define `Formula`, `Formula.neg`, `Formula.dia` and, for `[DecidableEq α]`, `Formula.subformulas`
as in the Conventions (Zach, Definitions 1.1–1.3, pp. 4–5, with the primitives reduced). Prove,
as API in prose: the subformulas of `φ` contain `φ`, are closed under taking immediate subformulas,
and number at most the number of constructor occurrences in `φ`.

**Checks.**
- `□p → p` has the three subformulas `□p → p`, `□p` and `p`; `◇p → □◇p` has seven, since `◇p`
  unfolds to `□(p → ⊥) → ⊥` and contributes `◇p`, `□(p → ⊥)`, `p → ⊥`, `p` and `⊥`.
- `p → p` has two subformulas, not three: subformulas form a set.

*Needs:* Mathlib `Finset`. (Proved here.)

### 1.2 Tautological instances and derivability

Define `boolEval v φ` for `v : Formula α → Prop`: variables and formulas `□ψ` are atoms whose
truth values `v` gives, `⊥` is false and `→` is material implication. Define `IsTautology φ` as
`∀ v, boolEval v φ`. Define the inductive predicate `Proves Ax`, the theorems of the normal system
with extra axioms `Ax`: tautological instances, every instance of the distribution schema
`□(φ → ψ) → (□φ → □ψ)` and the members of `Ax` are theorems, and theorems are closed under modus
ponens and under necessitation `φ / □φ` (Zach, Definitions 3.1–3.3, pp. 39–40, and Definition
3.10, p. 42; the schema `dual` of Definition 3.5 holds by definition of `◇`). Define
`Derives Ax Γ φ`: for some finite list `ψ₁, …, ψₙ` of members of `Γ`, the formula
`ψ₁ → (ψ₂ → ⋯ (ψₙ → φ))` is a theorem (Zach, Definition 3.36, p. 56).

- When `α` is infinite, `IsTautology φ` holds exactly when `φ` is a substitution instance of a
  modal-free tautology, the notion of Zach, Definition 1.14, p. 12: replace the distinct maximal
  atoms of `φ` by distinct variables. For finite `α` there may be too few variables for this, and
  `IsTautology` is the notion used throughout.
- `Derives Ax ∅ φ ↔ Proves Ax φ`; `Derives` is monotone in `Γ` and in `Ax`, contains `Γ`, is
  closed under cut and satisfies the deduction theorem
  `Derives Ax (insert ψ Γ) φ ↔ Derives Ax Γ (ψ → φ)` (Zach, Proposition 3.37, pp. 56–57).
- The rule rk: if `Proves Ax (φ₁ → ⋯ → φₙ → φ)` then `Proves Ax (□φ₁ → ⋯ → □φₙ → □φ)` (Zach,
  Proposition 3.6, p. 41).

**Checks.**
- `□p → □p` and `¬¬□p → □p` are tautological instances; `□p → p` is not (give `□p` the value
  true and `p` the value false). A plausible wrong evaluation that looked through `□` (treating
  `□ψ` as `ψ`) would make `□p → p` a tautology and so a theorem of K, which 2.4 refutes.
- `□(p → p)` is a theorem of K by necessitation but not a tautological instance, since `□(p → p)`
  is an atom for `boolEval`.
- With `α` a one-element type and `p` its variable, `□p → (□□p → □p)` is a tautological instance
  (its atoms are `□p` and `□□p`), but it is not a substitution instance of a modal-free
  tautology in `p` alone: such a tautology is not `p` itself, so matching it against the formula
  forces `p` to stand for both `□p` and `□□p`. This is why the first bullet above assumes `α`
  infinite.
- `Derives ∅ {p} (□p)` fails (by 2.4, with the model of the Check there), although `□p` is true
  in every model in which `p` is true at every world. A definition that allowed necessitation on
  hypotheses would derive it, and the soundness theorem of 2.4 for local consequence would fail.

*Needs:* Mathlib `List.foldr`. (Proved here.)

### 1.3 Schemas and the six systems

Define the schemas `axT`, `ax4`, `axB`, `ax5` as the ranges of the maps `φ ↦ □φ → φ`,
`φ ↦ □φ → □□φ`, `φ ↦ φ → □◇φ` and `φ ↦ ◇φ → □◇φ` (Zach, Table 2.1, p. 23). Define the Geach
formula `geachFormula h i j k φ`, which is `◇ʰ□ⁱφ → □ʲ◇ᵏφ`, the Geach schema `geachAxioms h i j k`
as the range of `geachFormula h i j k`, and for a set `S` of parameter tuples the union
`geachSystemAxioms S` (Garson, §9). Define `ModalSystem` with the six constructors `K`, `T`, `K4`,
`S4`, `KTB`, `S5`, and `ModalSystem.axioms`: none for K, `axT` for T, `ax4` for K4, `axT ∪ ax4`
for S4, `axT ∪ axB` for KTB and `axT ∪ ax5` for S5 (Zach, Definition 3.29, p. 53, defines S4 as
KT4 and S5 as KTB4; 1.4 shows that KT5 has the same theorems).

**Checks.**
- `axT`, `ax4`, `axB` and `ax5` are the Geach schemas with parameters `(0, 1, 0, 0)`,
  `(0, 1, 2, 0)`, `(0, 0, 1, 1)` and `(1, 0, 1, 1)`; the schema D, `□φ → ◇φ`, is `(0, 1, 0, 1)`.
- The parameters `(0, 0, 0, 0)` give the tautological instances `φ → φ`, so they add nothing.

*Needs:* Mathlib `Set.range`, `Set.iUnion`, `Nat.iterate`. (Definitions.)

### 1.4 Two axiomatizations of S5

Prove `proves_axT_union_ax5_iff`: `Proves (axT ∪ ax5) φ ↔ Proves (axT ∪ axB ∪ ax4) φ` for every
`φ` (Zach, Proposition 3.30, p. 53, posed as an exercise).

Route: it suffices to derive each axiom of one system in the other. In KT5 the schemas B and 4 are
theorems, and in KB4 the schema 5 is a theorem (Zach, Proposition 3.28 (1), (2), (4), pp. 51–52),
using the dual forms `φ → ◇φ` of T and `◇□φ → □φ` of 5 (Zach, Definition 3.26 and Proposition
3.27, pp. 50–51) and the rule rk of 1.2. Alternatively, both systems are complete for equivalence
relations by 3.4.

**Checks.**
- Without T the two axiomatizations differ: the frame with arrows `0 → 1` and `1 → 1` is
  euclidean and not symmetric, so it validates 5 and refutes B (2.2), and K5 does not prove B,
  while KB4 does.
- T is needed on both sides: the one-world frame with no arrow validates B, 4 and 5 (every `□ψ`
  is true there and every `◇ψ` false) and refutes `□⊥ → ⊥`, so neither KB4 nor K5 proves T, by
  2.4.

*Needs:* 1.2, 1.3. (Proved here, following the cited route.)

### Examples

The theorems `□(p ∧ q) → □p`, `◇(p ∨ q) → ◇p ∨ ◇q` and `¬◇⊥` of K, each with a derivation from
tautological instances, distribution, modus ponens and necessitation.

### Dependencies

Mathlib `Finset`, `List.foldr`, `Set.range`, `Set.iUnion`, `Nat.iterate`. No other layer.

## Layer 2: Kripke semantics, correspondence and soundness

### 2.1 Models, validity and local consequence

Define `Sat R V w φ`: a variable `p` is true at `w` when `w ∈ V p`, `⊥` is never true, `φ → ψ` is
true when `φ` is false or `ψ` is true, and `□φ` is true at `w` when `φ` is true at every `w'` with
`R w w'` (Zach, Definition 1.7, p. 9). Define `FrameValid R φ`: `Sat R V w φ` for every valuation
`V` and world `w` (Zach, Definition 2.4, p. 25). Define `Entails C Γ φ` as in the Conventions
(Zach, Definition 1.23, pp. 16–17, for the class of all frames).

- `Sat R V w (◇φ)` holds exactly when `φ` is true at some `w'` with `R w w'` (Zach, Proposition
  1.8, p. 9).
- Every tautological instance is true at every world of every model (Zach, Proposition 1.16,
  p. 14), and every instance of distribution is valid on every frame (Zach, Proposition 1.19,
  p. 15).

**Checks.**
- At a world with no successor, `□⊥` is true and `◇(⊥ → ⊥)` is false.
- On the frame `0 → 1` with `p` true only at `0`, `p` is true at `0` and `□p` is false there:
  this is the countermodel for the third Check of 1.2.

*Needs:* 1.1, 1.2; Mathlib `Set`. (Proved here, except as cited.)

### 2.2 The Lemmon–Scott correspondence

Define `relPow R n` by `relPow R 0 = Eq` and `relPow R (n + 1) = Relation.Comp R (relPow R n)`, and
`Convergent h i j k R`: for all `x`, `y`, `z`, if `relPow R h x y` and `relPow R j x z`, then some
`u` has `relPow R i y u` and `relPow R k z u` (Garson, §9, "hijk-Convergence").

- `frameValid_geachFormula_var_iff`: for a variable `p`, the formula
  `FrameValid R (geachFormula h i j k (var p))` holds if and only if `Convergent h i j k R`
  (Garson, §9, stated there for the schema; Lemmon and Scott, 1977).
- `forall_frameValid_geachAxioms_iff`: if `α` is nonempty, every member of `geachAxioms h i j k`
  is valid on `R` if and only if `Convergent h i j k R`.
- In particular a frame validates `□p → p`, `□p → □□p`, `p → □◇p` or `◇p → □◇p` if and only if
  it is reflexive, transitive, symmetric or euclidean, respectively (Zach, Corollary 2.8, p. 28,
  with Theorems 2.1 and 2.6, pp. 22–27), and `□p → ◇p` if and only if every world has a successor.

Route. If `R` is convergent and `◇ʰ□ⁱφ` is true at `x`, pick `y` with `relPow R h x y` where `□ⁱφ`
is true; for each `z` with `relPow R j x z` the convergence gives `u` with `relPow R i y u`, where
`φ` is true, and `relPow R k z u`, so `◇ᵏφ` is true at `z`; this proves the schema form and so the
variable form. Conversely, given `x`, `y`, `z` as in the definition, take `V p` to be the set of
worlds reached from `y` in `i` steps; then `◇ʰ□ⁱp` is true at `x`, so `□ʲ◇ᵏp` is true at `x`,
so `◇ᵏp` is true at `z`, and the world it provides is the required `u`.

**Checks.**
- `Convergent 0 1 0 0 R` is reflexivity, `Convergent 0 1 2 0 R` is transitivity,
  `Convergent 0 0 1 1 R` is symmetry, `Convergent 1 0 1 1 R` is the euclidean property and
  `Convergent 0 1 0 1 R` says that every world has a successor. On all frames with at most three
  worlds and all parameters in `{0, 1, 2}` (43,011 cases), frame validity of the Geach formula
  agrees with convergence.
- Correspondence is about frames, not models. On the cycle `0 → 1 → 2 → 0` with the same value of
  every variable at all three worlds, the rotation is an automorphism of the model, so all worlds
  satisfy the same formulas and every instance of T and of 4 is true at every world, while the
  frame is neither reflexive nor transitive. With `p` true only at `1`, both `□p → p` and
  `□p → □□p` fail at `0`.
- The schema form needs a variable. For empty `α` every formula is built from `⊥`, and on the
  cycle `0 → 1 → 2 → 0` all three worlds satisfy the same such formulas, so every instance of T is
  valid on that frame although it is not reflexive.
- The roles of `i` and `k` in the conclusion cannot be exchanged. With them exchanged, the
  parameters `(0, 1, 2, 0)` of 4 would ask that `R x y` and `R y z` imply `R z x`; the transitive
  frame with arrows `0 → 1`, `1 → 2` and `0 → 2` validates 4 and fails that condition.

*Needs:* 1.3, 2.1; Mathlib `Relation.Comp`. (Proved here, following the cited route.)

### 2.3 Universal frames

- `entails_equivalence_iff_universal`: local consequence over equivalence relations coincides with
  local consequence over universal relations (Zach, Proposition 2.14, p. 32, for valid formulas;
  the same restriction of a model to the class of the world gives the form with hypotheses).
- `not_exists_frameValid_iff_universal`: no formula `φ` has `FrameValid R φ ↔ ∀ x y, R x y` for
  every frame `R` on every type in the universe of `α` (Zach, §2.5, p. 30).

Route for the second: a formula valid on all universal frames is valid on all equivalence
relations by the first statement, so on the two-element frame whose relation is equality, which is
not universal.

**Checks.**
- Equality on a two-element type is an equivalence relation that is not universal, so the classes
  of the first statement differ although their consequence relations agree.
- Reflexive euclidean relations are exactly the equivalence relations (Zach, Proposition 2.12,
  p. 31); this was checked on all relations on at most three points.

*Needs:* 2.1; Mathlib `Equivalence`, `ULift`. (Proved here, except as cited.)

### 2.4 Soundness and the frame classes of the six systems

Prove `entails_of_derives`: if every member of `Ax` is valid on every frame of the class `C`, then
`Derives Ax Γ φ` implies `Entails C Γ φ` (Zach, Theorem 3.31, p. 53, for theorems; the
hypotheses are discharged at the world by modus ponens). Define `ModalSystem.frameClass`: all
frames for K, `∀ x, R x x` for T, `∀ x y z, R x y → R y z → R x z` for K4, both for S4,
reflexivity and `∀ x y, R x y → R y x` for KTB, and `Equivalence R` for S5.

- Each member of `L.axioms` is valid on every frame of `L.frameClass`, by the direction of 2.2
  from convergence to validity, which needs no variable, and, for S5, by 2.3's Check that
  equivalence relations are reflexive and euclidean.

**Checks.**
- The frame `0 → 1` with `p` true only at `0` refutes `p → □p` at `0`, so `Derives ∅ {p} (□p)`
  fails, as 1.2 states.
- The one-world frame without arrow refutes `□⊥ → ⊥`, so K does not prove T. The reflexive
  closure of the path `0 → 1 → 2`, with `p` true at `0` and `1` only, refutes `□p → □□p` at `0`,
  so T does not prove 4.

*Needs:* 1.2, 1.3, 2.1, 2.2, 2.3. (Proved here, except as cited.)

### Examples

The truth values of `□p`, `◇p`, `□◇p` and `◇□p` at each world of the three-world cycle and of the
path `0 → 1 → 2`, under each valuation of `p`.

### Dependencies

Layer 1; Mathlib `Set`, `Relation.Comp`, `Equivalence`, `ULift`.

## Layer 3: canonical models and strong completeness

### 3.1 Consistency and Lindenbaum's lemma

Define `Consistent Ax Γ` as `¬ Derives Ax Γ ⊥` (Zach, Definition 3.39, p. 57) and
`IsMaxConsistent Ax Γ`: `Γ` is consistent and contains `φ` or `¬φ` for every `φ` (Zach,
Definition 4.1, p. 62). Prove `exists_isMaxConsistent_of_consistent`: every consistent set is
contained in a maximal consistent set, for an arbitrary type of variables.

- `Derives Ax Γ φ` holds if and only if `insert (¬φ) Γ` is inconsistent (Zach, Proposition 3.40
  (2), p. 57).
- A maximal consistent set contains every formula derivable from it, contains `φ → ψ` exactly when
  it omits `φ` or contains `ψ`, and omits `⊥` (Zach, Proposition 4.2, p. 62).
- `Derives Ax Γ φ` holds if and only if `φ` belongs to every maximal consistent superset of `Γ`
  (Zach, Corollary 4.4, p. 65).

Route: Zorn's lemma, `zorn_subset_nonempty`, applied to the consistent supersets of `Γ` ordered by
inclusion. The union of a nonempty chain of consistent sets is consistent, because a derivation
uses only a finite list of hypotheses, all of which lie in one member of the chain. A maximal
element contains `φ` or `¬φ`, since one of `insert φ Δ` and `insert (¬φ) Δ` is consistent (Zach,
Proposition 3.40 (3), p. 58). When the variables, and so the formulas, are countable, the
enumeration of Zach, Theorem 4.3, pp. 63–64, gives the same set without choice.

**Checks.**
- The set of formulas true at a world of a model is maximal consistent in K, by 2.4.
- `{□p, ◇¬p}` is not refuted by tautological reasoning alone, since `□p` and `□¬¬p` are
  distinct atoms for `boolEval`, but it is inconsistent in K: rk applied to the tautology
  `p → ¬¬p` gives `□p → □¬¬p`, and `◇¬p` is `¬□¬¬p`.

*Needs:* 1.2; Mathlib `zorn_subset_nonempty`. (Proved here, except as cited.)

### 3.2 The canonical model and the truth lemma

Define `CanonicalWorld Ax`, the subtype of maximal consistent sets; `canonicalRel Ax Γ Δ`: `φ ∈ Δ`
whenever `□φ ∈ Γ`; and `canonicalVal Ax p`, the worlds containing `var p` (Zach, Definition 4.11,
p. 68). Prove `sat_canonical_iff`: `Sat (canonicalRel Ax) (canonicalVal Ax) Γ φ ↔ φ ∈ Γ`, for
every set `Ax` of extra axioms (Zach, Proposition 4.12, p. 68).

Route: induction on `φ`; the case `□φ` uses that `□φ ∉ Γ` makes `{ψ | □ψ ∈ Γ} ∪ {¬φ}` consistent
(rk of 1.2, Zach, Lemma 4.7, p. 66), and Lindenbaum's lemma extends it to a successor of `Γ`
omitting `φ` (Zach, Proposition 4.8, p. 67).

**Checks.**
- For K the canonical relation is not reflexive: `{□p, ¬p}` is K-consistent (it is true at the
  world of the one-world frame without arrow, with `p` false), and a maximal consistent extension
  contains `□p` but not `p`, so it does not see itself. Reflexivity comes from the axioms, by 3.3.
- If `Ax` proves `⊥` there are no maximal consistent sets and the canonical frame is empty; the
  truth lemma holds vacuously.

*Needs:* 1.2, 2.1, 3.1. (Proved here, following the cited route.)

### 3.3 Canonicity of the Geach schemas

Prove `convergent_canonicalRel`: if every member of `geachAxioms h i j k` is a theorem of `Ax`,
then `canonicalRel Ax` is `(h, i, j, k)`-convergent (Lemmon and Scott, 1977, as Garson, §9,
reports; Zach, Theorem 4.16, p. 71, for D, T, B, 4 and 5).

- In the canonical model, `relPow (canonicalRel Ax) n Γ Δ` holds if and only if `φ ∈ Δ` whenever
  `□ⁿφ ∈ Γ`, and then `◇ⁿφ ∈ Γ` whenever `φ ∈ Δ`.

Route: given `relPow R h x y` and `relPow R j x z`, the set `{φ | □ⁱφ ∈ y} ∪ {χ | □ᵏχ ∈ z}` is
consistent. Otherwise, using that `□ⁱ` distributes over conjunction, some `φ` with `□ⁱφ ∈ y` and
some `χ` with `□ᵏχ ∈ z` have `φ → ¬χ` a theorem; then `◇ʰ□ⁱφ ∈ x`, so `□ʲ◇ᵏφ ∈ x` by the axiom,
so `◇ᵏφ ∈ z`, while rk gives `□ᵏχ → □ᵏ¬φ` and `□ᵏ¬φ` is K-equivalent to `¬◇ᵏφ`. A maximal
consistent extension `u` of that set satisfies `relPow R i y u` and `relPow R k z u` by the
bullet above.

**Checks.**
- With `Ax = axT` the conclusion is the reflexivity of the canonical relation; with `Ax = ∅` the
  hypothesis fails for `(0, 1, 0, 0)` and the first Check of 3.2 shows the conclusion fails too.

*Needs:* 1.2, 1.3, 2.2, 3.1, 3.2. (Proved here, following the cited route.)

### 3.4 Strong completeness

- `derives_geachSystemAxioms_iff`: for every set `S` of parameter tuples,
  `Derives (geachSystemAxioms S) Γ φ` holds if and only if `φ` is a local consequence of `Γ` over
  the frames that are convergent for every tuple in `S` (Garson, §9, for theorems).
- `ModalSystem.derives_iff_entails`: for each of the six systems,
  `Derives L.axioms Γ φ ↔ Entails L.frameClass Γ φ` (Zach, Theorem 4.17, p. 72, for theorems).

Route: soundness is 2.4 with 2.2. For completeness, if `φ` is not derivable from `Γ` then
`insert (¬φ) Γ` is consistent (3.1); a maximal consistent extension is a world of the canonical
model at which, by 3.2, every member of `Γ` is true and `φ` is false, and by 3.3 the canonical
frame lies in the class. For the six systems, the classes of 2.4 are the convergence classes of
the corresponding tuples, by 2.2 and, for S5, by Zach, Proposition 2.12, p. 31.

**Checks.**
- With `S = ∅` the first statement is the strong completeness of K over all frames.
- Taking `Γ = ∅` gives weak completeness: the theorems of each system are exactly the formulas
  valid on its frame class.
- Every frame of the S5 class, an equivalence relation, satisfies the conditions of KTB, S4, T
  and K4, so every theorem of those systems is a theorem of S5.

*Needs:* 2.2, 2.4, 3.1, 3.2, 3.3. (Proved here, following the cited route.)

### Examples

The canonical models of T and of S5 restricted to the maximal consistent sets that contain a
given formula, and the canonical worlds through which a non-theorem of K4 fails.

Layers 1 and 2; Mathlib `zorn_subset_nonempty`.

## Layer 4: filtrations and the finite model property

### 4.1 Filtrations

Define `IsSubformulaClosed Φ` (Zach, Definition 5.1, p. 78). For a model `(R, V)` define the
setoid `agreeSetoid R V Φ`, under which two worlds are equivalent when they agree on every member
of `Φ` (Zach, Definition 5.2, p. 79); the valuation `filtrationVal R V Φ`, true at a class when
the variable is true at some member (Zach, Definition 5.4 (3), p. 80); and
`IsFiltration R V Φ R'` for a relation `R'` on the classes: `R x y` implies `R' [x] [y]`, and
`R' [x] [y]` with `□φ ∈ Φ` and `□φ` true at `x` implies `φ` true at `y` (Zach, Definition 5.4
(2), p. 80; the clause for `◇` there is not needed, since `◇` is defined from `□`).

- `sat_filtration_iff`: if `Φ` is closed under subformulas and `R'` is a filtration, then
  `Sat R' (filtrationVal R V Φ) [x] φ ↔ Sat R V x φ` for every `φ ∈ Φ` and every world `x`
  (Zach, Theorem 5.5, p. 80).
- `card_quotient_agreeSetoid_le`: if `Φ` is finite, there are finitely many classes and at most
  `2 ^ Φ.ncard` of them (Zach, Proposition 5.12, pp. 84–85).

Route for the bound: send a class to the set of members of `Φ` true at its members; this map into
the subsets of `Φ` is injective by definition of the setoid.

**Checks.**
- On the transitive frame with arrows `1 → 0`, `1 → 2` and `2 → 0`, with `p` true only at `2` and
  `Φ = {p}`, the classes are `{0, 1}` and `{2}`.
- In that example the bound is `2 ^ 1 = 2` and is attained.
- The theorem needs `IsSubformulaClosed Φ`. On the one-world frame with no arrow and `p` false,
  take `Φ = {□□p}`: there is one class, and the relation that relates it to itself is a
  filtration, since `□p` is true at the world. In the filtered model `p` is false at the class and
  the class sees itself, so `□□p` is false there, although it is true at the world.

*Needs:* 1.1, 2.1; Mathlib `Setoid`, `Quotient`, `Set.image`, `Set.Finite`, `Set.ncard`,
`Finite.of_injective`, `Nat.card_le_card_of_injective`, `Finset.card_powerset`. (Proved here,
except as cited.)

### 4.2 Filtrations that keep the frame conditions

Let `Φ` be closed under subformulas. Prove the following existence statements, named here in
prose.

- Every filtration of a reflexive model is reflexive, and every filtration of a universal model
  is universal (Zach, p. 87, before Theorem 5.18, and proof of Proposition 5.15, p. 86).
- The finest filtration, which relates `[x]` and `[y]` when some members are related by `R`, is a
  filtration (Zach, Definition 5.7 and Proposition 5.8, p. 82); it is symmetric when `R` is.
- The symmetric filtration, which relates `[x]` and `[y]` when `□φ` true at either one forces `φ`
  at the other for every `□φ ∈ Φ`, is symmetric, and it is a filtration when `R` is symmetric
  (Zach, Theorem 5.18 (1), pp. 87–88).
- Lemmon's transitive filtration, which relates `[x]` and `[y]` when every `□φ ∈ Φ` true at `x`
  has both `φ` and `□φ` true at `y`, is transitive, and it is a filtration when `R` is transitive
  (Zach, Theorem 5.18 (2), pp. 87–88, posed as an exercise).

**Checks.**
- The finest filtration need not be transitive. In the example of 4.1 it has the arrows from
  `{0, 1}` to itself, from `{0, 1}` to `{2}` and from `{2}` to `{0, 1}`, but none from `{2}` to
  itself. Lemmon's filtration of the same model relates every pair of classes, since `Φ` has no
  formula `□φ`.
- On random models with up to six worlds in each of the six classes, and random formulas of depth
  at most four, the finest, the coarsest, the symmetric and Lemmon's filtrations were checked to
  be filtrations with the stated frame properties, to keep every subformula, and to have at most
  `2 ^ |Φ|` classes.

*Needs:* 2.1, 4.1. (Proved here, except as cited.)

### 4.3 The finite model property

- `ModalSystem.proves_iff_forall_fin`: for each of the six systems and every `φ`, `φ` is a theorem
  if and only if `FrameValid R φ` for every `n ≤ 2 ^ (subformulas φ).card` and every relation `R`
  on `Fin n` in the system's class (Zach, Propositions 5.14, p. 85, for K and Corollary 5.16,
  p. 86, for S5, without the bound in the statement; the bound is that of Proposition 5.12).
- `proves_S5_iff_forall_fin_universal`: `φ` is a theorem of S5 if and only if it is valid on the
  universal frame on `Fin n` for every `n ≤ 2 ^ (subformulas φ).card` (Zach, Proposition 5.15 and
  Corollary 5.16, pp. 85–86).

Route: soundness gives one direction. If `φ` is not a theorem, 3.4 with `Γ = ∅` gives a model on a
frame of the class and a world where `φ` is false. Filter it through the subformulas of `φ` with
the finest filtration for K, T and KTB, and Lemmon's filtration for K4 and S4. For S5, first
restrict the model to the class of the world, which gives a universal model in which `φ` still
fails (2.3), and then take any filtration. By 4.1 the result has at most `2 ^ s` worlds and
refutes `φ`; by 4.2 its frame lies in the class; transport it to `Fin n` along a bijection.

**Checks.**
- `□p → □□p` is a theorem of K4 but not of K or T: the path `0 → 1 → 2` with `p` true only at `1`
  refutes it at `0`, a reflexive closure of the same path with `p` true at `0` and `1` refutes it
  at `0`, and both frames have three worlds, within the bound `2 ^ 4 = 16`.
- `◇p → □◇p` has seven subformulas and is valid on every universal frame (checked on at most four
  worlds), as a theorem of S5 must be.
- On `Fin 0` every formula is valid; the statements quantify over all `n` up to the bound, and a
  countermodel always has at least one world.

*Needs:* 2.3, 2.4, 3.4, 4.1, 4.2; Mathlib `Fin`, `Finset.card`. (Proved here, except as cited.)

### Examples

The filtrations through the subformulas of `□p → □□p` of the transitive model on `ℕ` with `R`
equal to `<` and `p` true at the even numbers, by the finest and by Lemmon's filtration.

## Scope and ownership

This roadmap owns the targets stated above: modal formulas over an arbitrary type of variables,
tautological instances, the Hilbert-style systems and derivability from hypotheses, the six
classical systems and the two axiomatizations of S5; Kripke semantics, the Lemmon–Scott
correspondence for Geach schemas, the comparison of equivalence and universal frames and the
non-definability of universality; strong soundness; Lindenbaum's lemma, the canonical model, the
truth lemma, canonicity of Geach schemas and strong completeness; filtrations, their size bound,
the filtrations that keep reflexivity, symmetry, transitivity and universality, and the finite
model property of the six systems.

Already in the libraries, and used as tools only: Mathlib's relation composition, iteration of
functions, setoids and quotients, cardinalities and Zorn's lemma, as listed in the supplier
contracts below. Mathlib's first-order model theory has maximal theories
(`FirstOrder.Language.Theory.IsMaximal`) and Tau Ceti has consistency properties for infinitary
first-order logic (`FirstOrder.Language.ConsistencyProperty`, the model existence theory of
InfinitaryModelExistence); both concern first-order languages, neither provides a propositional
or modal proof system, and neither is used.

Not treated here: Craig interpolation for modal logic. The Craig interpolation theorem of
InfinitaryModelExistence (Layer 7) is about sentences of infinitary first-order logic, a different
statement, and nothing here uses it. The other logic roadmaps on main (InfinitaryLogic,
InfinitaryModelExistence, CountableModelCounting, CountableStructureSpaces,
BorelEquivalenceRelations, ComputabilityTheory) concern first-order and infinitary languages,
descriptive set theory and computability, and share no object with this one.

Outside the scope: intuitionistic propositional logic and its Kripke semantics; Sahlqvist's
correspondence and canonicity theorems beyond the Geach schemas; the Goldblatt–Thomason theorem
and bisimulation invariance in general; Löb's logic GL and other logics of converse well-founded
frames; temporal, epistemic, dynamic and multi-modal logics; first-order modal logic;
decidability as a statement about procedures, tableaux, sequent calculi and complexity; and
algebraic semantics by modal algebras.
