## Where this roadmap stands

**At a glance.** The roadmap has only just begun. In Layer 0, one of the five concrete models of finite subgroups of SU(2) is built: the binary dihedral family. The other models, Klein's classification and Layers 1–7 have not started.

### Named results

- **The binary dihedral group as a subgroup of SU(2)**: for every n ≥ 1, the matrices r = diag(exp(πi/n), exp(−πi/n)) and s = !![0, 1; −1, 0] generate an actual subgroup of the native matrix group, [`binaryDihedralSubgroup`](https://taucetiproject.org/docs/TauCeti/RepresentationTheory/SU2/BinaryDihedral.html#TauCeti.SU2.binaryDihedralSubgroup). It is [isomorphic to Mathlib's dicyclic group `QuaternionGroup n`](https://taucetiproject.org/docs/TauCeti/RepresentationTheory/SU2/BinaryDihedral.html#TauCeti.SU2.binaryDihedralEquiv) through a [faithful representation](https://taucetiproject.org/docs/TauCeti/RepresentationTheory/SU2/BinaryDihedral.html#TauCeti.SU2.binaryDihedralHom_injective).
- **Normal forms and order of the binary dihedral group**: every element is uniquely r^j or s·r^j with j < 2n ([`mem_binaryDihedralSubgroup_iff`](https://taucetiproject.org/docs/TauCeti/RepresentationTheory/SU2/BinaryDihedral.html#TauCeti.SU2.mem_binaryDihedralSubgroup_iff)), so the group has [exactly 4n elements](https://taucetiproject.org/docs/TauCeti/RepresentationTheory/SU2/BinaryDihedral.html#TauCeti.SU2.natCard_binaryDihedralSubgroup). The relations r^(2n) = 1, s² = r^n = −1 and s r s⁻¹ = r⁻¹ are proved for the actual matrices. For n = 1 the group is cyclic of order four, as the roadmap's check requires.

### Notable definitions and infrastructure

- **Unit quaternions as SU(2)**: the roadmap's first step for Layer 0 is already in the library as `Quaternion.unitaryEquivSpecialUnitaryGroup`, built on the matrix embedding `Quaternion.toComplexMatrix`. The binary dihedral generators are matched with the quaternions cos(π/n) + sin(π/n)i and j through this embedding, which is the coordinate side the tetrahedral, octahedral and icosahedral models will need.
- **The double cover SU(2) → SO(3)**: `TauCeti.SU2.toSO3` exists, with its kernel identified as the centre of SU(2). The pole-set route to classification in 0.2 lifts rotation conjugacies through this map. The cover is supplied from LieGroups, not built here.
