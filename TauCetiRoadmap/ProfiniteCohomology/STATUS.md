### Named results

The cyclic case is [`abelianizationProPClass_generates_of_isCyclic`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/RepresentationTheory/Homological/ContCohomology/CohomologicalDimension/ClassModule/Cyclic/SecondCohomology.html#TauCeti.abelianizationProPClass_generates_of_isCyclic).
- **The strict-dimension criterion** — NSW (3.3.4): `scd_p G ≤ n` exactly when `cd_p G ≤ n` and the `p`-primary part of `H^{n+1}(U, ℤ)` vanishes for every open `U` ([`strictCohomologicalDimensionLE_iff_forall_openSubgroup`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/RepresentationTheory/Homological/ContCohomology/CohomologicalDimension/IntegralCriterion.html#TauCeti.strictCohomologicalDimensionLE_iff_forall_openSubgroup)).
- **Hilbert 90 and the Kummer isomorphism** — continuous `H¹(G_K, (Kˢ)ˣ)` vanishes, so `Kˣ/(Kˣ)ⁿ ≅ H¹(G_K, μₙ)` for `n` invertible in `K` ([`TauCeti.hilbert90`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/FieldTheory/GaloisCohomology/Hilbert90.html#TauCeti.hilbert90), [`TauCeti.kummerIso`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/FieldTheory/GaloisCohomology/Kummer.html#TauCeti.kummerIso)).
- **The cohomological dimension of `ℤ̂`** — `cd_p ℤ̂ = 1` for every prime `p`, and the upper bound holds because profinite extensions of `ℤ̂` split ([`zHat.cohomologicalDimensionAt_eq_one`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/Topology/Algebra/Group/Profinite/ZHat/CohomologicalDimension.html#TauCeti.zHat.cohomologicalDimensionAt_eq_one)).
- **The index-two Evens norm** — for an open subgroup `U` of index two, a map `H¹(U, 𝔽₂) → H²(G, 𝔽₂)` defined by descending the graph class ([`evensNormIndexTwo`](https://taucetiproject.github.io/TauCeti/docs/TauCeti/RepresentationTheory/Homological/ContCohomology/Evens/IndexTwoNorm.html#TauCeti.ContCohomology.evensNormIndexTwo)). On classes it equals the pullback of the `D₁₆` extension class (`evensNormIndexTwo_eq_ind_pullback`).
